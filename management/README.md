# 管理记录

本目录保存不面向站点读者的内部材料，包括站点方向、迁移审核和来源清单。这里的文件
不会加入 MkDocs 导航；当前有效的仓库规则以根目录 `CLAUDE.md` 为准。

- `site-direction.md`：站点定位、参考分析与后续调整方向。
- `migration-review.md`：文章迁移的审核结论和逐项记录。
- `myissues-migration.md`：myIssues 的 Issues 与 Discussions 迁移索引。
- `myissues-repository-files.md`：myIssues 普通仓库文件的迁移索引。
- `source-inventory.csv`：迁移来源属性清单。
